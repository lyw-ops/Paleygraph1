## Question
Can the actual transverse q=b+cr projection improve the summed rich right distribution?

## Why this call is worth making
The true r and b squared row masses are O(p^(3/2−3/418)), and the fixed-a first mass is now smaller. For c nonzero, summed a uses convolution of the q projection and the b row.

## Current proof obligation
Reach O(p^3/2) for the full weighted diagonal or the sufficient match estimates. In particular the genuine distinct-pole coupling, generic summed right energy and zero match remain open.

## Scope
Set x=1/Y and y=1/D, with y=x(x+q−1−c)/(qx−c) on genuine rows where the denominator is nonzero. Handle cancelled rows and zero denominators before testing paired quotient incidence or a direct mixed second moment. Keep both square masks and the actual g at all levels. A per-row gain has to be distinguished from a summed generic gain.

## How the result changes the next decision
- If supported: Prove a strict improvement of the whole actual rich energy or the target scale.
- If refuted: Identify a true field-uniform obstruction to the transverse projected estimate.
- If inconclusive: Give a new weighted transverse bound, including exceptional rows, and precise scope.
