## Question
Which actual Picard residual terms have the same five derived types and Jacobi exponents as the named linear fields?

## Why this call is worth making
The five new centers cannot cancel one another by exact label pooling under seed powers alone, but actual residuals can contribute to the same labels.

## Current proof obligation
Close a same-row signed budget, or find actual residual and transported returns for the linear remainder. Separate physical invariant margins and genuine growing depth.

## Scope
Begin at the first exact outgoing activation or first explicit return. Track determinants, both lift phases, actual marks, h=601 and 602, and the original square; keep posttransport collisions separate.

## How the result changes the next decision
- If supported: Compute a genuine signed returning coefficient or prove it vanishes, then give a bound on the residual terms needed to reach the linear budget.
- If refuted: Give exact category or parity obstruction for the specified objects and word lengths.
- If inconclusive: Name a first pair of actual objects and determine the smallest potential matching arity.
