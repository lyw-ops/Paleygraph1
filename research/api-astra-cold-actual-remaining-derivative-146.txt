## Result

For the actual eligible prime family
\[
p\equiv1\pmod 4,\qquad n=(p-1)/2,
\]
with the physical marking
\[
t_0=n,\qquad t_i=t\in Q
\]
off the marked coordinate, and \(Q\) the original closed square centered at \(2031/128\) with half-width \(2^{-17}\), the cited bounds do **not** yet prove that the selected contracting derivative absorbs the omitted terms.

Write, in the physical translated \(P_{5000}\) norm,
\[
A_h=KD_h,\qquad
J=KD^{\mathrm J},\qquad
L=KD^{\mathrm L},
\]
where
\[
D^{\mathrm L}_i=\alpha Y_i d'_{t_i}(S_i)
\]
uses the actual predictor coefficient \(\alpha\), and
\[
B=J+L=K(D^{\mathrm J}+D^{\mathrm L}).
\]

The accepted selected estimate is
\[
\|B\|_{P_{5000}}<0.959,
\]
with the selected two-step estimate below \(0.920\) in the corresponding two-pair calculation. These bounds price only the selected Jacobi and linear Legendre block; they do not price \(A_h-B\).

### What the available remainder estimate gives

The resummed actual-remainder calculation gives, at \(h=601,602\),
\[
\|KE_h^{(1)}\|_{P_{5000}}<0.527,
\qquad
\|K(E_h-E_h^{(1)})\|_{P_{5000}}<0.142,
\qquad
\|KE_h\|_{P_{5000}}<0.666,
\]
where \(E_h=D_h-D^{\mathrm J}\).

However, the cited material does **not** identify
\[
E_h^{(1)}=\alpha Y\,d'(S)
\]
with the selected \(D^{\mathrm L}\). The former is described as the first linear term
\[
d'_t(S)\,C_h,
\]
while the latter is the specifically chosen Legendre term
\[
\alpha Y\,d'_t(S).
\]
Thus
\[
A_h-B
 =K\bigl(E_h-D^{\mathrm L}\bigr)
 =K(E_h-E_h^{(1)})
  +K(E_h^{(1)}-D^{\mathrm L}).
\]
Only the first summand is bounded by \(0.142\). The mismatch
\[
K(E_h^{(1)}-D^{\mathrm L})
\]
has not been priced. Even if one grants the stronger, unproved identification \(E_h^{(1)}=D^{\mathrm L}\), the available bound is merely
\[
\|A_h-B\|_{P_{5000}}<0.142,
\]
not the required \(0.041\).

The total remainder estimate gives only
\[
\|A_h-B\|_{P_{5000}}
 \le \|KE_h\|+\|KD^{\mathrm L}\|
 <0.666+0.487=1.153,
\]
which is weaker still and counts no cancellation.

### Two-step reduction using the actual height change

The physical same-marking height comparison gives
\[
\|A_{602}-A_{601}\|_{P_{5000}}<0.017.
\]
Using the full height-601 rate
\[
\|A_{601}\|_{P_{5000}}<1.048,
\]
we obtain
\[
\|(A_{602}-A_{601})A_{601}\|_{P_{5000}}
 <0.017\cdot1.048
 =0.017816.
\]
Therefore
\[
A_{602}A_{601}-B^2
 =
(A_{602}-A_{601})A_{601}
 +(A_{601}^2-B^2),
\]
and the requested \(0.080\) two-step bound would follow from the same-row signed estimate
\[
\boxed{\ \|A_{601}^2-B^2\|_{P_{5000}}<0.062184\ }.
\]

This is a valid reduction on the original closed square with the actual physical floors and actual \(\alpha\). It is currently open.

For comparison, the crude factorization
\[
A_{601}^2-B^2=(A_{601}-B)A_{601}+B(A_{601}-B)
\]
would require a substantially sharper per-row error than the advertised \(0.041\) if one uses only
\[
\|A_{601}\|<1.048,\qquad \|B\|<0.959:
\]
indeed \(0.041(1.048+0.959)=0.082287\). Hence the two-step route needs either a signed product estimate or a per-row bound closer to \(0.0398\), unless additional asymmetric information is used.

## Precise remaining gap

The selected block calculation proves contraction of \(B\), but it does not establish any of the following:

1. that the actual first remainder sector \(E_h^{(1)}\) equals the selected \(\alpha Yd'(S)\) sector;
2. that the difference between them has physical \(P_{5000}\)-price below \(0.041\);
3. that the remaining analytic orders, other physical centers, marked derivative correction, higher Legendre powers, and Picard residuals have a signed combined price below \(0.041\);
4. or directly that
   \[
   \|A_{601}^2-B^2\|_{P_{5000}}<0.062184.
   \]

The finite signed pool separation through the displayed quintic order does not close this gap: it separates several named generic labels, but it does not supply a complete signed price for every omitted sector of the full marked derivative. The nonlinear invariant and the half-step remain independent obligations and have not been used here.
